Co zostało zrobione

  • Nowe narzędzie ops/elitedesk/gmail_cleanup.py (stdlib Python, bez pip). Kroki: auth → inventory → classify → apply / undo.
  • Inwentaryzacja metadanych wszystkich 107 201 wiadomości do SQLite (~/.local/state/home-ops/gmail/inventory.sqlite) przez IMAP + OAuth (XOAUTH2): 4 minuty. REST API było limitowane do ~3 msg/s (~10 h), więc służy tylko do zapisu etykiet (batchModify).
  • Klasyfikacja: każdy mail dostaje dokładnie jedną kategorię. Kolejność: reguły nadawców z gmail_rules.json → własne maile według odbiorcy → ludzie (adresy, do których Piotr pisał, i freemail bez List-Unsubscribe, z wyłączeniem adresów automatycznych) → zakładki Gmaila → Inne/Do-przejrzenia.
  • Zapis: 34 etykiety (zagnieżdżone, widoczne w panelu). Narzędzie tylko dodaje etykiety: bez archiwizacji, bez zmiany przeczytania, bez kasowania. Dziennik JSONL umożliwia undo.

Jak przetestować ręcznie

  1. Wymagane: ~/.config/home-ops/gmail-client.json (klient OAuth „Desktop”, projekt home-ops-seo) oraz token gmail-token.json (python3 ops/elitedesk/gmail_cleanup.py auth).
  2. Testy jednostkowe: 
    python3 -m unittest discover -s ops/elitedesk/tests -p 'test_*.py'
    Oczekiwane: 100 testów OK (32 dotyczy Gmaila).
  3. Inwentaryzacja (tylko odczyt, ok. 4 min): 
    python3 ops/elitedesk/gmail_cleanup.py inventory
    Oczekiwane: 107201 messages in All Mail ….
  4. Raport na sucho: 
    python3 ops/elitedesk/gmail_cleanup.py classify
    Sprawdź ~/.local/state/home-ops/gmail/classify-report.md: suma kategorii = liczba maili, Inne/Do-przejrzenia poniżej 1%.
  5. W Gmailu wyszukaj has:nouserlabels -in:chats. Wynik powinien obejmować tylko maile nowsze niż ostatnia inwentaryzacja.
  6. Kliknij kilka etykiet w panelu (np. Prawne, Ludzie, Finanse/Faktury) i oceń trafność próbek.
  7. Cofanie (nie uruchamiać bez potrzeby): 
    python3 ops/elitedesk/gmail_cleanup.py undo ~/.local/state/home-ops/gmail/journal-20261024-184848.jsonl
    Usuwa tylko etykiety dodane przez narzędzie.

Przypadki brzegowe

  • Uszkodzone nagłówki (CR/LF w adresie, błędne kodowanie RFC 2047): parser jest tolerancyjny, co pokrywa test.
  • Polski folder „[Gmail]/Wszystkie”: nazwę wykrywa atrybut \All, nie stała.
  • Limity API (403 „Quota exceeded”): adaptacyjny ogranicznik AIMD oraz ponawianie przy timeoutach sieci.
  • Token OAuth w trybie „Testing” wygasa po 7 dniach (31.10). Trzeba opublikować aplikację (Branding → Publish) i raz powtórzyć auth.
