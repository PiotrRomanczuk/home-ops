Co zrobiono

Jak przetestować ręcznie

  1. Kliknij Później przy dowolnym PR. Po systemctl --user start pr-decide.service pytanie nie wraca, a w jego miejsce wchodzi następny najstarszy PR.
  2. Odrzuć z powodem → po przebiegu PR zamknięty z komentarzem „Odrzucone w home-ops Decisions: …”.
  3. Scal przy PR z zielonym CI → PR scalony, gałąź usunięta. Log: journalctl --user -u pr-decide -n 5.
