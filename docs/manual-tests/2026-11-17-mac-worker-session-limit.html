args, state = sys.argv[1:], os.environ['SPRINT_STATE']

now = datetime.now(timezone.utc)
if '/usage' in args:

tid = next(a for a in args if a.startswith('sprint:'))[7:]

if tid.startswith('session-'):

Przypadki brzegowe do obejrzenia na żywo

  • Pierwszy prawdziwy limit po włączeniu joba: w runs.jsonl wynik limit, w queue/ pola not_before/resume, nic w failed/.
  • Komunikat limitu tygodniowego może mieć datę („resets Nov 23, 5pm (Europe/Warsaw)”) — format zgadnięty; jeśli będzie inny, zadziała zapas z /usage albo +15 min.
  • Sesja z --resume, której CLI nie znajdzie, skończy się zwykłym retry (pole resume jest wtedy usuwane, druga próba startuje od zera).
  • Stop joba w trakcie zadania (rc 143) → zadanie w queue/ z interrupts: 1 i tym samym modelem.
