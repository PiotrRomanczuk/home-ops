Jak sprawdzić instalację ręcznie (robi Piotr)

  1. W katalogu repo: cd ops/mac/gpu && sudo ./install-gpu.sh (opcjonalnie z gpu-jobs.json jako argumentem).
  2. Oczekiwane: skrypt kończy się bez błędu i wypisuje code: /usr/local/libexec/mac-worker. Brak ModuleNotFoundError.
  3. ls /usr/local/libexec/mac-worker — jest 6 plików: gpu_worker gpu_jobs gpu_report gpu_pause machine procs (.py), właściciel root.
  4. Po restarcie nadzorcy: tail -n 5 ~/.local/state/home-ops/sprint/gpu/log.jsonl — zdarzenie start, brak pętli restartów; cat ~/.local/state/home-ops/sprint/gpu/status.json odświeża się co ~30 s.
  5. Przypadek brzegowy: w kopii roboczej (nie w /usr/local) usuń gpu_pause.py i uruchom /usr/bin/python3 -B -c 'import sys; sys.path.insert(0, sys.argv[1]); import gpu_worker' <katalog> — oczekiwane ModuleNotFoundError: gpu_pause; to ten sam błąd, który skrypt instalacyjny teraz łapie przed restartem usługi.
  6. Przejście między zadaniami: w log.jsonl przy porzuconym zadaniu kolejno shard-failed (fails=3), stopped (powód „zadanie porzucone”), job-done; kolejne started dotyczy już następnego zadania.
