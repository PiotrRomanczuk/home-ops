3. Przypadki brzegowe

  • Crawl nieosiągalny → ostrzeżenie w journalu, karta i plan bez zmian, exit 0.
  • Claude zwraca zepsuty JSON → narracja zapisana, plan nietknięty.
  • Sędzia niedostępny (timeout) → brak "ok": true → diff wyrzucony. Celowo: bez recenzji nic nie wychodzi.
  • Ta sama hipoteza proponowana drugi raz → ON CONFLICT DO NOTHING.
  • Finding znika z crawla → resolved z datą; wraca → ponownie open, dismissed zostaje.
