Mac worker: zatrzymanie runnera nie zostawia procesów claude

Data: 2026-11-17 · PR: #83 (feat/claude-sprint), poprawki r4 z recenzji review-r14-ho79-83 · Zakres: ops/mac/sprint

Co zrobiono

  • Problem: od r3 każdy przebieg claude ma własną grupę procesów (twardy limit czasu). Przez to nie należy już do grupy joba launchd: launchctl kickstart -k, bootout czy reinstalacja zabijały tylko runner.py. claude pracował dalej jako sierota, a nowy runner przenosił jego zadanie z running/ do queue/ i uruchamiał je drugi raz.
  • run_groups.py (nowy): rejestr żywych grup (LIVE). stop_all() wysyła TERM, a po 10 s KILL, i od tej chwili nie pozwala wystartować nowemu przebiegowi. Grupa (pgid, czas startu systemu, czas startu lidera) trafia do pliku zadania w running/.
  • lifecycle.py: handler SIGTERM wywołuje shutdown(): flaga halted w pamięci (bez pliku STOP), stop_all, do 30 s na to, żeby workery odłożyły zadania jako interrupted. Potem wyjście z kodem 0, w limicie ExitTimeOut 60 s. Tak samo działa wyjście z kodem 1 po padnięciu wątku (watch()).
  • sprint_tasks.setup(): po SIGKILL albo awarii zatrzymuje grupę z pliku zadania, jeśli to nadal ta sama grupa (ten sam boot i ten sam lider, czyli PID nie został użyty ponownie). Potem liczy przerwanie (interrupts +1) i dopiero wtedy przenosi zadanie do queue/.
  • Przy okazji: local.max_minutes (domyślnie 20) to twardy limit każdego local:*, a planner.md wstrzymuje local:*/bench-*. Utracona sesja (No conversation found) kończy się interrupted bez resume. Do listy zakazów doszło Bash(git push * --force*), sprawdzone na żywo. Lista py_compile w check.yml jest uzupełniona, a install.sh kopiuje też procs.py.

Jak przetestować ręcznie

Bez install.sh i bez LaunchAgentów. Runner działa z osobnym SPRINT_STATE w /tmp, a atrapa CLAUDE_BIN (skrypt sh) odpowiada na /usage i przy zadaniu robi sleep 300 we wnuku. SIGTERM wysłany ręcznie to ten sam sygnał, który launchd wysyła przy kickstart -k i bootout.

Skrypt scenariusza

#!/bin/bash
# sigterm-demo-83.sh <sprint dir> — runner with a fake claude: SIGTERM, restart, SIGKILL, restart
SPRINT=$1; T=$(mktemp -d /tmp/sigterm-demo.XXXX); S=$T/state; mkdir -p $S/queue $T/vault/3-Zasoby/analysis
W=$(/usr/bin/python3 -c 'from datetime import *; print((datetime.now(timezone.utc)+timedelta(days=6)).isoformat())')
cat > $T/claude <<F
#!/bin/sh
if [ "\$2" = /usage ]; then echo '{"usage_report":{"rate_limits":{"limits":[{"kind":"session","percent":1,"resets_at":"$W"},{"kind":"weekly_all","percent":1,"resets_at":"$W"}]}}}'; exit 0; fi
echo "\$\$ \$(echo "\$@" | grep -o 'sprint:[a-z]*')" >> $T/starts
sleep 300 & wait
F
chmod +x $T/claude
echo '{"claude":{"workers":2,"windows":["daily 00:00-00:00","daily 12:00-12:00"]}}' > $S/config.json
for id in one two; do printf -- "---\nid: $id\nmodel: sonnet\nmax_minutes: 5\ncwd: $T\n---\ndo $id\n" > $S/queue/$id.md; touch -t 202601010000 $S/queue/$id.md; done
export SPRINT_STATE=$S CLAUDE_BIN=$T/claude SPRINT_PLANNER=0 SPRINT_VAULT=$T/vault
start() { /usr/bin/python3 $SPRINT/runner.py 2>>$T/runner.err & R=$!; for i in $(seq 200); do [ $(cat $T/starts 2>/dev/null | wc -l) -ge $1 ] && break; sleep 0.2; done; sleep 0.5; }
fakes() { pgrep -f "$T/claude" | wc -l | tr -d ' '; }
echo "== 1. start runner (pid via start)"; start 2; echo "fake claude processes running: $(fakes)"; grep -h pgid $S/running/*.md
echo "== 2. SIGTERM to runner (what launchctl kickstart -k / bootout sends)"; t0=$(date +%s); kill -TERM $R; wait $R; echo "runner exit code: $? after $(( $(date +%s)-t0 )) s"
echo "fake claude processes left: $(fakes)"; echo "running/: $(ls $S/running)"; grep -h -E "^(id|model|attempts|interrupts|not_before):" $S/queue/*.md
echo "== 3. clear not_before and restart: each task starts exactly once more"; sed -i '' '/^not_before/d' $S/queue/*.md; touch -t 202601010000 $S/queue/*.md; start 4; echo "starts so far:"; cat $T/starts; echo "fake claude processes running: $(fakes)"
echo "== 4. SIGKILL to runner (no handler can run)"; kill -KILL $R; wait $R 2>/dev/null; sleep 0.5; echo "fake claude processes left after SIGKILL: $(fakes) (orphans, as expected)"; echo "running/: $(ls $S/running)"
echo "== 5. restart: setup() stops the orphans before requeueing"; start 6; echo "starts so far:"; cat $T/starts; echo "fake claude processes running: $(fakes) (only the 2 new runs)"
kill -TERM $R; wait $R; echo "final exit code $?; fake claude left: $(fakes)"; echo "failed/: $(ls $S/failed)  (third interruption = MAX_INTERRUPTS)"; grep -h -E "^(id|interrupts):" $S/failed/*.md
echo "runner stderr:"; cat $T/runner.err; rm -rf $T
