3. Jak przetestować ręcznie

A. Bez serwera (Mac)

cd ~/Desktop/MainCV/home-ops
python3 -m unittest discover -s ops/elitedesk/tests -p 'test_*.py'     # oczekiwane: OK, 15 testów
python3 -m py_compile ops/elitedesk/seo-analyse.py ops/elitedesk/seo_*.py
bash -n ops/elitedesk/seo-improve.sh

B. Na elitedesk — analiza bez danych (sprawdza degradację)

ssh uwh
cd ~/code/logs-stack && git pull
docker exec -i home-ops-postgres-1 psql -U postgres -d home_ops -v ON_ERROR_STOP=1 -f postgres/migrations/018_seo_analysis.sql
set -a; . ops/elitedesk/seo-collect.env; set +a
python3 ops/elitedesk/seo-analyse.py
# oczekiwane: JSON {"gsc_rows": 0, "narrative": false, ...}, plik digest.d/seo-gitarawarszawa-pl.txt
#             z linią „(brak danych w tym oknie …)”, 1 wiersz w seo_analysis_daily
cat ops/elitedesk/digest.d/seo-gitarawarszawa-pl.txt

C. Na elitedesk — pełny przebieg (po kluczu Google i claude login)

systemctl --user start seo-collect.service && journalctl --user -u seo-collect -n 20
# oczekiwane: "seo-collect done: {'gsc:gitarawarszawa.pl': N, 'ga4:gitarawarszawa.pl': M}"
systemctl --user start seo-analyse.service && cat ops/elitedesk/digest.d/seo-gitarawarszawa-pl.txt
# oczekiwane: sekcje DZIELNICE i TOP FRAZY z liczbami + narracja po polsku (≤ 22 linie, 3 rekomendacje)
docker exec -i home-ops-postgres-1 psql -U postgres -d home_ops -c \
  "select day, model, length(narrative), metrics->'areas'->0->>'label' from seo_analysis_daily order by day desc limit 3"
# następnego ranka: mail 07:00 ma kartę „seo gitarawarszawa pl”

D. Tygodniowy PR

bash ops/elitedesk/seo-improve.sh --dry-run | head -60   # sam prompt z briefem, nic nie edytuje
systemctl --user start seo-improve.service; journalctl --user -u seo-improve -f
# oczekiwane: "claude exited 0", bramki zielone, "PR opened on seo/auto-YYYY-MM-DD";
# gh pr list --label seo-auto pokazuje 1 PR; drugie uruchomienie tego dnia → "an open seo-auto PR already exists"

4. Przypadki brzegowe

  • Wylogowany claude: seo-analyse kończy się kodem 0, karta bez narracji, w journalu „claude narrative unavailable”. seo-improve pomija z kodem 0.
  • Brak migracji 018: karta zapisana, ale wyjście 1 z „save failed (migration 018 applied?)”.
  • Czerwone bramki w gitara-lekcje: diff wyrzucony (git checkout -- . && git clean -fd), wyjście 1, brak pusha.
  • Ponowne uruchomienie tego samego dnia: upsert po (site, day, kind), bez duplikatów.
  • Fraza pasująca do kilku dzielnic: wygrywa pierwszy wzorzec w seo-districts.json (np. „praga-północ” przed ogólną „praga”).
