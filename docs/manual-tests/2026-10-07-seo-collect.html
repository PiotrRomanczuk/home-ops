Jak przetestować po wdrożeniu

  1. Na uwh: cd ~/code/logs-stack && git pull && scripts/apply-migrations.sh && docker compose up -d --build ingest
  2. Utwórz ops/elitedesk/seo-collect.env z przykładu, uzupełnij INGEST_TOKEN, SEO_SA_JSON, PLACES_API_KEY.
  3. Uruchom ręcznie (patrz README) — oczekiwane: "failed": [] i liczby wierszy w summary.
  4. Zapytania SQL z sekcji „Verify” w ops/elitedesk/README.md pokazują dane dla obu stron i 5 konkurentów.
  5. Edge case: usuń konto serwisowe z jednej usługi GSC → ten krok w failed, pozostałe dalej się zapisują.
